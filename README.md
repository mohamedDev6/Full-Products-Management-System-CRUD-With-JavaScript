## 🧠 1. Overview

This is a **Full Product Management System (CRUD Application)** built using **HTML, CSS, and Vanilla JavaScript**.

The project simulates a real-world product management system where users can **add, search, update, and delete products**, with data persistence using **Local Storage**.

This project focuses on strengthening **JavaScript logic, DOM manipulation, and problem-solving skills**.

---

## ✨ 2. Features

- ➕ Add new products with details:
  - Product Name  
  - Product ID  
  - Category  
  - Price  
  - Quantity  

- 💾 Store data using **Local Storage**

- 🔍 Search products by:
  - Name  
  - ID  
  - Category  

- ✏️ Update product information

- 📉 Decrease product quantity

- 🗑️ Delete:
  - Single product  
  - All products (Clear system)

- 🔄 Dynamic UI updates without page reload

---

## 🛠️ 3. Tech Stack

- HTML5  
- CSS3  
- Vanilla JavaScript  
- Local Storage API
